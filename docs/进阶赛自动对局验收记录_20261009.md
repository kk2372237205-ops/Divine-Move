# 进阶赛自动对局验收记录

日期：2026-10-09  
规程依据：`reference/第三届人工智能算法实践与应用赛项赛竞赛规程.pdf`（进阶赛部分）

## 本次可验证事实

- 上位机在 `1920×1080` 画面中完成棋盘标定；日志记录为棋盘无异物。
- 用户在比赛开始前进行一次“比赛自动执行”授权，程序随后通过 `COM7` 的 DEBUG 会话执行机器人黑棋回合。
- 全局日志共记录 `18` 次 `robot_move_started`，均为 `mode=automatic`；`18` 次均随后得到 `robot_move_visually_confirmed`。机器人黑棋坐标依次见原始 JSONL。
- 对局共 `36` 子，满足规程的“双方合计不少于 20 子”。终局事件为“白棋五连，人类获胜”，程序正常结束，之后不再安排机械臂动作。
- 黑棋在 `(7,5)`、`(7,6)`、`(7,7)`、`(7,8)` 形成四连，可作为 AI 主动形成连续棋型不少于三子的证据。

## 不能由本记录单独证明的事项

- “人类形成连续三子时 AI 至少一次阻断”的特定场景，仍需单独摆盘或回放核验；白棋最终获胜不能替代该项证据。
- 机械臂的无碰撞、无取放失败、无 2 秒及以上明显卡顿，需要现场连续视频或人工观察记录；本 JSONL 能证明动作启动与视觉落子确认，不能测量碰撞或动作平顺性。
- 棋局可视化的每一手颜色、坐标和 UI 同步，需用连续录屏逐手复核；终局截图只能作为终局一致性的辅助证据。

## 结论

本局已经有力证明“视觉识别 → AI 决策 → 一次授权后的自动黑棋取放 → 落子视觉确认 → 正常判胜”的完整主流程。它是进阶赛的重要实机证据，但不能据此宣称四项评分点已经全部验收完毕。
